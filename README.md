# AshLSnow — 情报归集库

个人情报收集的归集地。多 Agent 协作采集、整理后统一归档到这里。

## 内容

- `intel/daily-briefing-YYYY-MM-DD.md` — 每日情报早报（马斯克、扎克伯格、黄仁勳、特朗普 + AI 行业热点 + 中国方向）
- `intel/` 下其他文件 — 专题追踪与分析（币安被盗案、黄仁勳 Megaspeed 疑云、美伊/俄乌、宏观与加密市场等），每条信息附来源链接与来源发出时间

## 规则

- 先存档再汇报：信息先压缩整理成带链接的 md 文件，再报最简结论。
- 溯源：每条信息注明来源及该来源发出的时间，尽量找源头时间；只给得出转载时间时明确标注。
- 迟发现的进展标明原发时间，不包装成当日新事；“报道”与“”分开标注。

## 更新

每日早报约 08:43（北京时间）更新；重大进展随时追加。
